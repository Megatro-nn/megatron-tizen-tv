# Changelog

## 1.0.0

First Megatron release, forked from Tessel 1.37.3.

- Five USB folder views: Large icons, Small icons, Tiles, List, Details
- Sort / View toolbar; sort by name, date, size or type in both directions
- Poster covers for folders, real thumbnails for photos, line icons for every file type
- Hold OK menu: Favorites and Forget watched; the left and right keys move between tiles
- Play all / Shuffle all rows off by default
- New name, icon and app ID so it installs next to Tessel
