# Changelog

## 1.0.1

- Removed the Apple and Mux sample stream buttons from the Play URL screen.
- New "Make a new code" button in Settings, Cast from another device, and a note to keep the pairing code private.
- Settings, Cast from another device now names the Megatron Send phone app (Android and iPhone) and uses the new send page address.
- New Settings option, Clock: show the time in 24-hour (default) or 12-hour format, on every screen and in the player (clock and "ends at" time).

## 1.0.0

First Megatron release, forked from Tessel 1.37.3.

- Five USB folder views: Large icons, Small icons, Tiles, List, Details
- Sort / View toolbar; sort by name, date, size or type in both directions
- Poster covers for folders, real thumbnails for photos, line icons for every file type
- Hold OK menu: Favorites and Forget watched; the left and right keys move between tiles
- Play all / Shuffle all rows off by default
- New name, icon and app ID so it installs next to Tessel
